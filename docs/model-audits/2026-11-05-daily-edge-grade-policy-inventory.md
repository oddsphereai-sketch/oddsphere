## Prioritized interpretation and shared-definition draft

1. **Fix demonstrable invariant contradictions first**, in separate sport-owned changes. NBA above is concrete. NHL's explicit professional-price exception and MLB/EPL/UCL value exceptions are intentional product routes; determine whether an owner-approved global expensive-Best/value invariant should apply to them before changing them.
2. **Uniform meanings, sport-specific entry evidence.** Best should mean the sport's strongest actionable selected-side recommendation: sufficiently strong final forecast or a specifically authorized causal evidence route, worthwhile exact offer, and no terminal execution/price restriction. Lean should mean useful actionable selected-side conviction at the stated price; an informational/parlay-only or shop-price opinion needs an explicit separate label when it is not a positive-value straight bet. This last semantic choice is not yet uniform in MLB/EPL/UCL.
3. **Do not standardize by copying 62%/−200 or deleting every contextual rule.** Three-way plurality, push rates, hockey discrete scores/puckline, FI uncertainty, MLB two-layer total qualification, and unavailable provenance genuinely differ. Intentional qualified alternate promotion routes may enter below the ordinary probability/edge band; all routes should still obey whatever terminal price/validity constraints the owner declares.
4. **Preserve one final forecast and exact economics.** Forecast-side p, loss, push, price, EV and comparator edge need explicit units/basis. Evidence points or `effectiveConfidence` must not masquerade as final win p. A negativeEV tuple can be a likely prediction; calling it wager value would be false. No alternate value-side switch, source quota, fixed model/book blend or fabricated sharp identity is implied by this inventory.
5. **Standardize transport semantics before numeric policies.** Explicit verdict, display label, wager status, canonical grade and reason should agree. `model_only` is not a cross-sport actionable-grade code: NBA/WNBA use it for Lean, while MLB compatibility may map it to Watch; `best_signal` is an encoding alias, not proof of observed sharp action. Existing stored locked fields have precedence over any new interpretation. NFL/CFB compact boards copy released tuples; CBB final runtime codecs were checked by the separate 43-case audit. This bounded inventory did not exhaustively execute every reader/version fallback.
6. **Reconsider restrictions only with their actual role understood.** NFL total-direction gate; CFB multi-channel confirmation, bounded evidence points, fallback caps and provisional lanes; NBA corroborated-opposition rule; WNBA point+probability double requirements and ten-book promotion lanes; MLB many overlapping grade sleeves; soccer originator/current support gates are candidates for a sport-owned review, not proven unnecessary merely because another sport omits them. Preserve qualified existing behavior, show promotion/demotion counts and boundary tests, avoid unverified historical accuracy claims.

Completion criteria for follow-up: freeze a source release per sport; record ordinary and alternate entry routes plus terminal invariants; test coherent tuples at boundaries and each alternative route; prove final writer/adapter/tracking grade and exact price agree; compare board counts with paired promotions/demotions; preserve locks; run model-change checks. No long new fitting exercise is necessary merely to fix a terminal grade invariant. Any forecast/input/calibration change requires its own model review.
