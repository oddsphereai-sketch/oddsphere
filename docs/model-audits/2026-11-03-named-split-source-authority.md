# Daily Edge named split source authority — November 3

Starting base: `6eb5df089155f0663c87b03efe5384c430621c10`; integrated CFB
source repair `5f8ce7bc8473aa8cefb9fb2a55987866be7b6f68` before publication.

The broad reader spot check confirmed a shared classification defect:
`alignMarketReadsToDisplayedSharpBookSplits` sent every complete fallback pair
through the sharp-only context API. DraftKings Network, DraftKings and BetMGM
consumer data could therefore set sharp_book_splits_available and professional
coverage true, regardless of the actual source. This did not itself change the
writer's score/grade, but made the displayed/internal evidence authority false.

Source-authority R1 classifies explicit source identity, never the display label.
Only the supported Circa named-book source establishes professional coverage.
DraftKings/Network and BetMGM remain retail, consensus remains public, and a
legacy section without identity is unclassified. Both sides and original clocks
are retained and their directional relationship remains readable as their own
source context. The compatibility named-source slot remains intact; it cannot
by itself establish professional availability. Professional evidence reason
codes are removed for retail/public/unknown sections. Missing-source state is
updated only for sports whose existing capability contract expects that source.

The post-decision overlay is still context-only. No regrading, score adjustment,
probability, selection, evaluated price, stake, provider request, polling job or
tracking writer is added. Board-count impact on identical input is zero
promotions/demotions. The production source release is carried in reason codes;
the persisted continuity schema/key stays R1 so genuine existing source history
is not discarded. Locked state or an existing lockedAt field wins before any
new semantics. Stored locks and their exact old reader evidence stay unchanged.

Focused tests exercise all seven generic sports × six source classes,
misleading Sharp labels, retained retail pairs, correct source flags, repeated
application without accumulating evidence, unchanged numerical/grade tuples,
and byte-exact legacy locked payloads (including contradictory open state with
a stored lock timestamp). Full model safety, type/lint/build, fresh-main
integration, protected PR and post-deploy source/reader proof are required.
The CBB-specific reader/UI classification is separately preserved from PR955.
This source-role repair is not a claim that every market signal changes a score
or that the current forecasts have become more accurate.
