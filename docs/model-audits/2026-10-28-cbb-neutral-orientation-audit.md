# CBB neutral-site orientation invariant: audit declaration

During the loss census, exact linear-head attribution showed that invariant
features such as projected Total, absolute margin and closeness contribute to
the *signed* home margin. A possible structural defect needs testing: on a truly
neutral court, swapping only the provider's home/away labels must preserve the
teams' score projections and winner probabilities after converting back to the
original team orientation. This is an input-symmetry test, not a hindsight flip
strategy. Actual home-court games are not subject to this identical invariant.

Test every accepted neutral-site game in the 5,721-game diagnostic cohort. Replay
the same frozen r2 state at the original midnight/six-hour cutoff and require
the original forecast to reproduce. Swap teams, use the identical available
historical statistics, and forecast again. Perform the same comparison for the
already-rejected r8 head. Neither label nor actual outcome is used to select an
orientation. Do not alter original predictions or count the better orientation
as an improvement. Report projection and probability discrepancies and how
often the predicted real-world winner changes solely from swapping labels.

No model change, new source call, writer, grade, lock or activation is authorized
by this audit. If the invariant fails, a symmetry-respecting candidate needs a
new release and chronological predictive/market evaluation before replacement.
