# NFL named-price chronology: private release contract

Owner's requested behavior: interpret market evidence as a coherent game,
not a display-only collection of signals or a fixed consensus blend.
This NFL change addresses a concrete missing input to that interpretation.
The independent statistical score is one datum in that read, not a protected
anchor or an opinion the market must defeat. Current independent, player-aware,
price, line, split, availability, and cross-market facts must resolve to one
margin/Total distribution and one set of score, probability, side, and grade
consequences. A static price or a split can change conviction without invented
points; a genuine price episode can move the score and cross a winner boundary
when the full evidence warrants it. A fixed score nudge, a source-count vote,
or selecting one existing whole-game forecast merely because it agrees is not
the requested unified read.

The existing Market Intelligence V2 leased collector owns Owl's Circa and
Pinnacle price observations. The NFL writer must read those append-only rows
by canonical game identity, bounded high-water mark and evaluation time.
Each market requires both sides from the same provider event, sportsbook,
ingestion run and source timestamp. Spread sides must be opposite numbers,
Total sides the same number, and Moneyline must have no line. Incomplete,
duplicated or future rows cannot be combined into a synthetic opening or
movement. Keep provider provenance `owls` in the compact context. The
BALLDONTLIE evaluated quote and target-excluded scoring remain separate.

The scenario checks cover: named ML price strengthening despite opposite
money/ticket flow; retail follow-through only after a named move; same-time
retail observation not counted as following; market-specific clock freshness;
opposite Moneyline winner and Spread cover; unavailable coherent score
candidate leaves the forecast unchanged with an explicit reason; and locked
reader/writer precedence. The cross-product 120-scenario catalog maintained
by the market-reader chat remains the broader contract; this NFL release does
not claim that all 120 cases pass in every sport.

A private pure Moneyline episode-transport operator and focused test now show
the missing consequence mathematically: a same-book two-sided fair-price
change can move a tight statistical score across zero, while the identical
price change can leave a strongly favored statistical score on its original
side. It uses relative log-odds displacement, not the current offered quote
as a score anchor. This is an explicit mathematical assumption, not proof of
predictive superiority. The operator is **not wired into the prediction
writer**: the reader must first resolve chronology, source disagreement,
news already consumed by the independent/player-aware inputs, and the
Moneyline/Spread/Total joint score law. Wiring it alone would risk double
counting one event or producing conflicting market predictions. No production
score, grade, or stake changes result from this pure operator.
The same private test now also exercises Spread and Total number-plus-de-vigged-
juice transport under the existing discrete score law: a number move with
exactly offsetting juice produces no invented point change, while an
uncompensated line move changes the appropriate margin or Total coordinate.
These isolated operators are not a substitute for one joint distribution;
their shifts must never be added independently as three votes.
The operator now requires a supplied statistical-source knowledge timestamp
before the selected quote opener. A whole price episode that overlaps newer
statistical input is rejected for transport; a separate pure selector can
choose the first and last exact same-book quotes after that knowledge time,
or return no episode if only a static current quote remains. Contradictory
same-time quotes reject the selection. The real writer has not yet connected
its provider timestamps and book tape to that selector. This is an
information-overlap check, not a minimum-move gate;
the focused test still transports a valid 0.1-percentage-point move.

function labeled `no-weight` classified a close independent score using a
weighted market score internally, and both it and the downstream three-state
reader could then *reflect* that score across zero or the Spread boundary.

score constructions, not observed market-implied margins. The private repair
classifies the independent law directly and requires a target-excluded,
same-line, paired-price-derived score candidate for a categorical correction.
The three-state stage no longer mirrors or halves a betting number when
that paired price is absent. A focused close-game regression proves a
qualified market may still reverse the winner without manufacturing a
12.7-point margin from a six-point line.
