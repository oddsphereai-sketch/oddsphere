published probability to its own offered-price break-even probability. At zero
or negative value label it Lean; the independently rounded published EV must
also be positive before retaining Best, so rounded probability cannot promote
an encoded zero/negative value. At positive value retain its original Best
qualification. Every existing Lean, Watchlist and No Play is unchanged. Invalid
Best probability/price inputs fail explicitly instead of inventing a grade.
There is no new probability threshold, price cap, fitted reserve, candidate,
market vote, side switch, provider request or rank quota. In particular this
cannot create or remove an actionable forecast or forbid a confidence Lean.

The paired promotion is ordinary fresh price recovery for the same original
eligible Best candidate. Both Over/Under remain actionable throughout; a better
real price that establishes positive value restores Best. At fixed selected
outcome/probability/stake, improving the quote leaves every possible loss/push/
void unit return unchanged and improves a winning return. Tests prove that
arithmetic for all outcome classes. This is not held-out accuracy evidence or
an empirical calibration claim. Any requirement for a further native-specific
policy exception must be resolved explicitly before release, never inferred.
