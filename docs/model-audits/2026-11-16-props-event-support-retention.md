# Event support navigation and original-actor retention

## Predeclared problem and repair

Completed correction responses can still omit required opposing event support,
or leave an unsupported numerical scope without an explicit exception. Mean
envelopes alone do not describe those event predicates. A full-part correction
can also replace an already valid NFL actor with an invalid answer; the existing
receipt-bound actor-retention path was enabled only for NBA.

The proposed R46 request exposes exact existing per-event admission requirements
next to the original market indices, including strict versus inclusive lines,
integer pushes, positive-weight support and the distinct independent-prior and
priced-event rules. Unsupported-stat action cues name the aligned exception
entry explicitly. They do not supply a probability, law, floor, new fact or
automatic decline, and they do not weaken any admission check. The event
enumeration is shared with the existing validator so navigation cannot describe
a different acceptance contract.

The same original-source/request/draft/known-receipt actor-retention machinery
will apply to NBA, NFL and MLB within the existing two phases. Only independently
admitted actors with a durable known-charge receipt can be retained. A later
answer cannot replace their original law or claims. Every actor and scope must
still be admitted before the whole game completes. Unknown charges, lost receipt
acknowledgements, unavailable archives and malformed envelopes remain blocking.
Offline receipt reconstruction never authorizes a closed-job replay. The pure
receipt auditor reuses the runtime model, actual-tier, reference and billing
verifiers, requires exact saved identity proofs and rejects repeated response
references across phases before retaining any actor.

## Scope and release

Shared generation R46, NBA writer R27 and NFL writer R107 will identify the
future-only request/runtime change. Law R3, grade R5, selection R8, independent
models, native MLB R44, quote/participation/source rules and first-lock authority
stay unchanged. All R45 and earlier accepted qualification metadata, requests,
laws and locks remain original. No additional model, phase, slot, output cap,
provider call, concurrency pool, schedule, lease or spending limit is introduced.
Exact normal input counting and whole-game funding include the navigation.

## Impact and verification

The same accepted law and execution quote must yield identical probabilities,
projections, grades and stakes. Test both actionable Over and Under recovery,
supported siblings and derived markets, scope-local honest abstention, genuine
negative yards, rare events, integer pushes, original-label/quote authority and
locked writer/reader precedence. Report synthetic promotion/demotion and actor
coverage counts; do not call a flatter board a repair. Archived failed responses
must remain rejected unless a separate, explicitly hypothetical offline control
returns a valid model answer; never publish or retrofit that control.

Required release gates are focused whole-product and adversarial tests, full
model/type/lint/build, exact hosted mandatory model and real disposable PostgreSQL
proofs with all AI HTTP mocked, two consecutive rounds of three fresh independent
whole-product reviewers on an unchanged candidate, latest-main overlap safety,
strict up-to-date/no-bypass protection, exact remote tested tree and expected-head
PR merge. Actual Ready/Current/Production/www/source and ordinary generation,
member publication, retention and locks remain necessary live verification.
The [OpenAI Structured Outputs guidance](https://developers.openai.com/api/docs/guides/structured-outputs) distinguishes schema adherence from application business-rule correctness; the original semantic validators therefore remain mandatory.
No paid proof or manual review is authorized. Code checks do not establish
empirical calibration or a guarantee that every future model response succeeds.

Rollback is a complete reviewed versioned source release. Preserve every old
forecast, result, receipt, closed slot and locked payload unchanged.
