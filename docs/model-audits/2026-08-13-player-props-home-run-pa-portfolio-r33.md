The prior single-highlight proposal was withdrawn. Home runs are evaluated as

## Why the first replacement failed

The broad all-market tournament represented each prior game as one equal
binary trial. That makes a one-plate-appearance game count the same as a
five-plate-appearance game and produced a generic regression selector that
went 3-57 on the untouched August holdout. That selector remains rejected.

R33 instead estimates home-run opportunity per plate appearance. It uses only
games strictly before the slate, excludes zero-PA appearances, takes the most
recent 20 games, shrinks the observed HR/PA rate with 100 league-average plate
appearances at 3.2% HR/PA, projects plate appearances from batting order,
applies verified park and outdoor-temperature context, and anchors the result
25% to the exact locked multi-book market consensus.
